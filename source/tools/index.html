Small tools I've built for my own use. The browser tools need no install -- just open and go, with all progress in localStorage. The desktop tools are open-source and available on GitHub.

🎯 Quizzer

A spaced-repetition flashcard app in one HTML file. Drop in a CSV deck and study. Great for language vocab, but works for anything.

  • 🧠 FSRS-4.5 spaced repetition
  • 📥 Import decks as CSV via drag-and-drop
  • 🎛️ Multiple study modes: spaced repetition, least practiced, random, browse
  • 📊 Session summaries, mastery charts, response-time breakdowns
  • 💾 Export / import full state as JSON
  • 🌍 Multi-language UI (EN, FR, NL, IT, TR, ES, EL, AR)

🌍 Translator

AI-powered translation practice. Pick a language pair, translate sentences, get instant feedback with adaptive difficulty.

  • 🗣️ 8 languages, any direction (EN, NL, ES, TR, DE, IT, EL, FR)
  • 🤖 Claude evaluates each attempt: score, ideal translation, grammar notes
  • 📈 Adaptive difficulty and CEFR sub-level tracking
  • 🔁 Periodically re-serves sentences you got wrong
  • 🔑 Bring your own API keys -- no server, no middleman

📅 SetDate

A lightweight Mac utility for batch-setting or batch-translating timestamps on photo and video files. Updates all EXIF fields and the Unix creation timestamp so your photo album files things into the right date on import.

  • 🖱️ Drag and drop files to load them
  • 📆 Batch set or batch translate dates
  • 🖼️ Updates EXIF metadata and filesystem creation date
  • 🍎 Mac OS (Apple Silicon) only
